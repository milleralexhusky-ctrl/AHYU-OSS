# 4.62.0 — 新增三条已核实免费条款的渠道预设

## 起因

WorkBuddy 的付费模型全线 `14018`，免费模型 `hy3` 能顶但单一。用户要求
"找更多方向、更新的资料、更多数据"——不是去换付费套餐，而是把**注册就送额度**
的渠道接进来。

翻了三份每日同步的资料库（`free-llm-intel`、`Free-LLM`、`awesome-freellm-apis`），
逐条核实后只挑出三家：**端点实测存在 + 免费条款明确 + OpenAI 兼容**。

## 新增的三条

| 预设名 | 端点 | 免费条款（核实于 2026-10-26） | 坑 |
| --- | --- | --- | --- |
| Z.AI（GLM Flash 免费） | `https://api.z.ai/api/paas/v4` | `glm-4.5-flash` / `4.7-flash` / `4.6v-flash` **真 $0**，不是试用金；免绑卡 | 限速官方不公布（第三方测约 1 req/s、1000 次/日）；模型能力中等 |
| IteraCompute（3000 万 tok/月） | `https://api.iteracompute.com/v1` | `qwen/qwen3.8-27b` **3000 万 token/月**，月初重置、不累积；免绑卡 | **只有这一个模型**；运营方不透明，可信度评分 55/100 |
| Hetzner Inference（实验免费） | `https://inference.hetzner.com/api/v1` | 实验期完全免费（无计费系统），两个 Qwen（262K 上下文、支持工具调用） | **要绑卡**（虽免费）；慢（4~50 tok/s）；无 SLA |

三条都属于「国外」分组（走境外出口）。

## 为什么只加这三条

同期扫到的其他"免费"渠道逐条排除：

- **LLM7.io**：号称免 Key，实测 67 个模型、**0 个免费档**，已全面收费；
- **HuggingFace**：原 \$0.10 免费额度已取消；
- **Together / DeepInfra / xAI**：无免费层；
- **GitHub Models**：本机直连不通（000，需梯子）；
- **Routeway / Onomeo / BazaarLink**：端点活着（401/403），但运营方背景查不到，
  额度说法只有聚合站转述，没有官方页佐证 —— 不放进预设，避免变成"看起来能选、
  选了就报错"的陷阱。

## 顺带提醒（写进预设名里，不是隐藏坑）

预设名直接标注了额度，用户在选择时就能看见 `IteraCompute（3000 万 tok/月）`，
而不是点进去才发现只有一个月度总额。这是 4.55.0 那次教训的延续：
**别让列表看起来比实际更能用**。

  不是 404；
